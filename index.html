하루모아 개인정보처리방침

시행일: 2026년 10월 26일

하루모아(이하 "앱")는 사용자의 개인정보와 데이터를 중요하게 생각합니다. 본 개인정보처리방침은 하루모아가 어떤 정보에 접근하고, 해당 정보를 어떻게 이용·저장·보호하는지 설명합니다.

1. 서비스 개요

하루모아는 일정 관리 및 가계부 기록 기능을 제공하는 Android 애플리케이션입니다.

사용자는 일정, 메모, 수입·지출, 결제 및 환불 내역 등의 정보를 직접 입력하여 관리할 수 있습니다.

하루모아는 현재 별도의 회원가입이나 사용자 계정 로그인을 요구하지 않습니다.

2. 처리하는 데이터

하루모아는 앱의 기능 제공을 위해 사용자가 직접 입력하거나 생성한 다음과 같은 정보를 처리할 수 있습니다.

  • 일정 날짜 및 시간
  • 일정 제목 및 메모
  • 가계부 수입·지출 내역
  • 금액 및 통화 정보
  • 카드 또는 결제수단에 사용자가 입력한 명칭
  • 가맹점 또는 사용처 정보
  • 결제, 취소 및 환불 기록
  • 사용자가 직접 설정한 앱 설정값

3. 데이터 저장

하루모아의 데이터는 사용자의 기기 또는 사용자가 직접 설정한 저장장치에 저장될 수 있습니다.

사용자가 NAS 연결 기능을 사용하는 경우 일정 및 가계부 데이터가 사용자가 직접 지정한 NAS로 전송되어 저장될 수 있습니다.

NAS 주소, 접속 환경 및 NAS에 저장된 데이터의 관리 책임은 해당 NAS를 설정하고 운영하는 사용자에게 있습니다.

하루모아 개발자는 사용자가 직접 운영하는 NAS에 저장된 일정 및 가계부 데이터를 개발자 소유의 중앙 서버에 별도로 저장하지 않습니다.

4. 인터넷 사용

하루모아는 사용자가 설정한 NAS와 데이터를 주고받거나 앱의 기능 제공에 필요한 네트워크 통신을 위해 인터넷 연결을 사용할 수 있습니다.

인터넷 권한 자체가 사용자의 개인정보를 개발자에게 자동으로 전송한다는 의미는 아닙니다.

5. 결제 알림 및 알림 접근 기능

하루모아에 결제 알림 자동등록 기능이 제공되는 경우, 사용자가 명시적으로 알림 접근 권한을 허용하고 대상 앱을 선택한 경우에 한하여 결제와 관련된 알림 내용을 처리할 수 있습니다.

해당 기능은 카드 사용내역, 결제 금액, 사용처, 결제 또는 취소 시점 등의 정보를 가계부 기록에 활용하기 위한 목적으로 사용됩니다.

하루모아는 금융기관 계정의 비밀번호, 인증번호 또는 금융 앱 로그인 정보를 수집하기 위한 목적으로 알림 접근 기능을 사용하지 않습니다.

사용자는 Android 설정에서 언제든지 하루모아의 알림 접근 권한을 해제할 수 있습니다.

알림 자동등록 기능이 포함되지 않은 버전에서는 다른 앱의 알림이나 문자메시지에 접근하지 않습니다.

6. 제3자 제공

하루모아 개발자는 사용자의 일정 및 가계부 데이터를 광고회사, 데이터 판매업체 등에 판매하지 않습니다.

또한 광고를 목적으로 개인정보를 제3자에게 제공하지 않습니다.

사용자가 직접 설정한 외부 서비스 또는 NAS 기능을 사용하는 경우, 해당 기능을 수행하는 데 필요한 데이터가 사용자가 지정한 서비스로 전송될 수 있습니다.

7. 광고 및 사용자 추적

하루모아는 현재 맞춤형 광고 제공을 목적으로 사용자의 행동을 추적하지 않으며, 광고 목적의 사용자 프로파일을 생성하지 않습니다.

향후 광고 또는 분석 기능이 추가되는 경우 실제 데이터 처리 방식에 맞게 본 개인정보처리방침 및 Google Play 데이터 보안 정보를 변경합니다.

8. 개인정보의 보유 및 삭제

앱 내부 또는 사용자의 기기에 저장된 데이터는 사용자가 해당 기록을 삭제하거나, 앱 데이터를 삭제하거나, 앱을 제거할 경우 삭제될 수 있습니다.

사용자의 NAS에 저장된 데이터는 사용자가 직접 NAS에서 삭제할 수 있습니다.

하루모아는 현재 별도의 중앙 사용자 계정을 운영하지 않으므로 개발자가 보유한 사용자 계정에 대한 별도의 계정 삭제 절차는 존재하지 않습니다.

사용자가 직접 운영하는 저장장치 또는 백업에 남아 있는 데이터는 해당 저장장치의 관리 방법에 따라 사용자가 직접 삭제할 수 있습니다.

9. 데이터 보호

하루모아는 앱 기능 수행에 필요한 범위 내에서만 데이터를 처리하도록 설계됩니다.

개인 NAS를 사용하는 경우 NAS 계정, 접속 토큰, 네트워크 및 저장장치의 보안 설정은 사용자가 적절히 관리해야 합니다.

10. 아동의 개인정보

하루모아는 아동의 개인정보를 수집하는 것을 주된 목적으로 하는 서비스가 아닙니다. 사용자가 직접 입력하는 일정 및 가계부 정보를 관리하기 위한 일반적인 생활 관리 애플리케이션입니다.

11. 개인정보처리방침 변경

앱 기능, 데이터 처리 방식 또는 관련 정책이 변경되는 경우 본 개인정보처리방침이 변경될 수 있습니다.

중요한 변경사항이 있는 경우 앱 또는 개인정보처리방침 페이지를 통해 알립니다.
